# Examples

Example NovaSharp programs will live here once the grammar specification is
available. They serve three purposes:

1. they are the first end-to-end tests (`ai-nsc run examples/<name>.nova`),
2. they document the language for readers,
3. they are the corpus the parser and semantic checks are validated against.

Naming: one directory per topic (`basics/`, `control-flow/`, `functions/`,
`types/`, ...), each holding runnable programs with a `// expect:` comment for
the expected output where useful.
